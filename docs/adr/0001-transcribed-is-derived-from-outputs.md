# Transcribed is derived from Outputs, not stored

Whether a Recording is Transcribed is decided by checking whether at least one of its Outputs exists in the current output location, in a currently enabled Format. vmt keeps no separate record of which Recordings it has transcribed. A stored record would go stale whenever a user deletes, moves, or renames Outputs by hand, and it would add a state file that every interface (CLI, TUI, Alfred, Raycast, Watch) would have to keep in step. The accepted cost: changing the output location or swapping out every enabled Format makes previously transcribed Recordings appear Pending, and `vmt transcribe --all` would then transcribe and bill them again. That command shows the count and total duration and asks for confirmation first, so the user sees it before paying.
